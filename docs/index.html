StarNet Etsy Connector

This HTTPS endpoint completes Etsy authorization for the locally operated StarNet seller dashboard. Credentials and shop data remain on the operator's computer.

Purpose

Read-only shop analytics and owner-reviewed product workflows for the operator's own Etsy shop.

Access

The application requests only the Etsy permissions needed to read shop, listing, and transaction data.

Data handling

Credentials and retrieved shop data remain on the operator's local computer and are not sold or shared.

Private application operated by the shop owner.
